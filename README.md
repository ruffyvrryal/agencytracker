# Agency Tracker

Shared job-tracking, income/expenses, and payroll app for a 3-person design studio.
See supabase/schema.sql for the database setup and .env.example for required env vars.

## Getting started

1. Create a Supabase project.
2. Run supabase/schema.sql in the Supabase SQL editor.
3. In Supabase Storage, create a public bucket named "project-photos".
4. Copy .env.example to .env and fill in your project URL + anon key.
5. npm install
6. npm run dev
